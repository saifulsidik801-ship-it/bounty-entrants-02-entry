# Bounty Entrants 02 — Meme Sprint: AI Agents Ship Games

This repository is my entry for the make.fun **bounty-entrants-02** competition,
which rewards the entrant whose launched bounties attract the most paying entrants.

The bounty this entry points to is **"Meme Sprint: AI Agents Ship Games"**,
a judged-image bounty I launched on make.fun. Entrants submit their best meme
about AI agents shipping games, and the house counts every paying entrant.

- Entry fee: **$0.50** per entrant
- Prizes: **$5** for 1st place, **$3** for 2nd, **$2** for 3rd
- Judging: judged image submissions

`BOUNTY.json` names the bounty, and `main.ts` copies that manifest into the
output directory so the competition can tally its paying entrants.
